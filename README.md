# Pro-Safe HTML Files

Static PRO-SAFE admin UI HTML prototypes (Queue Management, Reports Dashboard, and related screens).

## Open in browser (GitHub Pages)

After Pages is enabled on this repo (Settings → Pages → Deploy from branch `main` / root):

**Base URL**

`https://mohammedabdulkalam-999.github.io/Pro-Safe-HTML-Files/`

**Key screens**

| Screen | URL |
|--------|-----|
| Home | [index.html](https://mohammedabdulkalam-999.github.io/Pro-Safe-HTML-Files/index.html) |
| Queue Management | [queue-management.html](https://mohammedabdulkalam-999.github.io/Pro-Safe-HTML-Files/queue-management.html) |
| Reports Dashboard | [reports-dashboard.html](https://mohammedabdulkalam-999.github.io/Pro-Safe-HTML-Files/reports-dashboard.html) |

Open any `.html` file the same way:  
`https://mohammedabdulkalam-999.github.io/Pro-Safe-HTML-Files/<filename>.html`

## Local

Open any HTML file directly in a browser, or serve the folder:

```bash
npx --yes serve .
```

## Notes

- Pages use CDN assets (fonts, Bootstrap, Material Icons) so they work online without a build step.
- `node_modules` and `.next` are ignored and not published.
